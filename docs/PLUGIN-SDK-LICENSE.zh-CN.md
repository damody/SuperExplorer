## 1. 范围与准据文本

本 Plugin SDK 许可条款（以下简称“SDK 许可”）规范 SuperExplorer 公开的插件 API、Header、Schema、示例、模板、文档、打包工具及其他明示属于 Plugin SDK 的材料（合称“SDK 材料”）。三个语言版本应具有相同含义；如有冲突，以本简体中文版本为准。

## 2. SDK 许可

在遵守本 SDK 许可的前提下，Damody 授予您全球、非独占、不可转让、不可再许可且可撤销的权利，仅可在设计、构建、测试、打包、记录及维护可与 SuperExplorer 互操作的插件（以下简称“插件”）所必要的范围内使用、复制及修改 SDK 材料。

您可以分发及收费销售包含自己原创代码与合法许可材料的插件。仅在插件兼容性及文档合理必要的范围内，您可以复制 API 声明、最小接口定义及示例片段。

## 3. 插件所有权

您与 Damody 之间，您保留原创插件代码、美术、文字及其他内容的著作权。Damody 保留 SuperExplorer、SDK 材料、接口、标志及项目自有资产的全部权利。本 SDK 许可不转让任何一方的著作权。

## 4. 独立发行

符合下列条件时，您可以自行免费或付费发行插件：

1. 除明示可再分发的 SDK 文件外，不包含、再分发、替代或暴露 SuperExplorer 核心代码或可执行文件；
2. 要求用户合法取得 SuperExplorer；
3. 遵守适用法律及所有第三方许可；
4. 准确说明兼容性及作者身份；且
5. 不造成安全、隐私、完整性或平台政策违规。

通过 Damody 的 Steamworks 账户、SuperExplorer 官方页面、捆绑包或其他官方渠道发行，必须另行接受[插件发布协议](PLUGIN-PUBLISHING-AGREEMENT.zh-CN.md)。

## 5. 商业使用

个人研究及开发独立插件可依本 SDK 许可进行。公司内部插件开发或员工工作使用 SuperExplorer，每位用户均须依 [EULA](EULA.zh-CN.md) 拥有有效商业席位：依结账或发票币种，每人每年 US$5 或 RMB¥30，另加依法应收税费。

## 6. 兼容性与 API 变更

Damody 不保证每个 API 或插件与所有软件版本兼容。插件必须准确声明支持版本及能力。基于兼容性、安全、法律或平台原因，Damody 可变更、弃用、禁用、隔离或移除接口或插件。在可行范围内，Damody 会记录重大 API 变更。

## 7. 限制

您不得：

1. 使用 SDK 材料建立或发行 SuperExplorer 核心应用程序的替代或竞争实现；
2. 将大量非 SDK 核心代码复制进插件；
3. 规避许可、沙箱、能力、签名、安全、完整性或审核控制；
4. 未经书面授权，声称插件是 Damody 官方、认证、背书或发布；
5. 在产品名称、域名、商店身份或标志中混淆使用 SuperExplorer 商标；
6. 隐瞒能力、网络行为、内置工具、数据收集或第三方代码；或
7. 分发恶意软件、违法内容或您无权许可的材料。

## 8. 插件标识与支持

插件必须标识作者、版本、必要能力、支持的 SuperExplorer 版本、重大数据处理行为、内置可执行文件及适用的第三方许可通知。对于独立发行的插件，您负责用户支持、维护、官方渠道以外的退款、安全修复及合规。

## 9. 反馈与贡献

只要不含机密信息，Damody 可无限制及无偿使用 SDK 反馈。对 SuperExplorer 核心或 SDK 材料的贡献，必须接受[贡献者许可协议](CLA.zh-CN.md)并遵守[贡献指南](CONTRIBUTING.zh-CN.md)。仅发行插件不构成核心贡献。
