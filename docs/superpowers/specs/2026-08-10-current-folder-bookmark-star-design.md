# 目前資料夾書籤星號設計

## 問題

書籤列的星號目前只根據檔案清單的單一選取項目啟用。使用者已經位於 `D:\UE4.26` 等實體資料夾時，如果沒有選取子項目，星號會停用，無法像 Firefox 收藏目前頁面一樣收藏目前資料夾。

## 核准行為

星號永遠代表目前分頁正在顯示的位置，不再代表檔案清單選取項目。

- 目前位置是實體檔案系統資料夾且尚未收藏時，顯示可操作的 `☆`。
- 按下 `☆` 後，立即新增目前資料夾書籤、持久化並顯示 `★`。
- 再按一次 `★`，立即移除相同目標的書籤、持久化並恢復 `☆`。
- 星號固定在書籤工具列最左側，維持 20 px 的醒目尺寸。
- 檔案清單是否有選取項目不影響星號目標。
- 非檔案系統位置（例如虛擬容器或無法解析路徑的 Shell namespace）停用星號，避免建立不可重建的書籤。
- Lua 書籤仍由 `+` 建立，不受此變更影響。

## 資料與事件流程

UI state 從目前分頁 history 的 current location 建立 `BookmarkTarget::Folder`，並用型別化目標查找既有 bookmark ID。工具列只投影 `未收藏／已收藏／不可收藏` 三種狀態。點擊沿用既有 bookmark mutation、durable session 通知與失敗 rollback；不再讀取檔案清單 selection。

## 錯誤處理

- 持久化失敗時回復 mutation，星號恢復操作前狀態並顯示非阻塞錯誤。
- 目前位置不存在或不是實體資料夾時停用，不建立資料。
- 已存在相同 Folder target 時只移除該目標，不影響同名但不同路徑的書籤。

## 測試與驗收

- 單元測試：目前實體資料夾能產生 Folder target；選取子項目不改變目標；非檔案系統位置不可切換。
- 模型測試：相同型別化目標可正確查找與移除。
- Headful UITEST：直接開啟 `D:\UE4.26` 或等價 fixture，不選取任何子項目，驗證 `☆ → ★ → ☆ → ★`。
- 截圖：保存未收藏與已收藏畫面，確認星號固定最左側且尺寸醒目。
