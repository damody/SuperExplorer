# 多工作傳輸中心與即時速度設計

## 目標

SuperExplorer 必須在 Local、ADB、SFTP 互傳時顯示可信的每秒速度，活動中的進度以 0.2 秒為更新節奏，並在多工作並行時提供不壓縮檔案清單的 Firefox 式傳輸中心。Shift+Delete 不得在執行期間占用底部傳輸狀態，只在操作終止後顯示結果。

## 已選定介面

採用 B 混合式版面：底部只顯示一筆摘要，右上工具列提供傳輸按鈕與浮動詳細面板。

- 底部摘要選擇最後啟動且尚未終止的傳輸工作。
- 最新工作先完成時，自動回退到較早但仍在執行的工作。
- 沒有活動傳輸時，顯示最後終止工作，並在第 7 至第 8 秒淡出。
- 右上按鈕徽章顯示活動傳輸數；點擊後顯示本次程式執行期間的全部操作記錄，最新在上。
- 面板記錄不跨程式重啟保存。
- 每個活動工作可獨立取消；終止工作提供開啟本機所在資料夾或導向遠端路徑的動作。

## 操作模型與排序

`OperationCenterState` 除了以 request ID 索引記錄，還保存穩定的插入順序。它公開以下語意查詢：

- `active_transfer_count`：尚未終止的 Copy／Move 工作數。
- `foreground_record`：最後啟動且仍在執行的傳輸；若沒有，則為最後終止且仍在八秒顯示期限內的工作。
- `records_newest_first`：供右上面板顯示本次執行期間記錄。

短操作不計入傳輸徽章。Shift+Delete 的 queued／running 記錄不成為底部 foreground；終止後可以成為完成通知，並保留於面板。

## 傳輸速度

速度是 UI 可呈現狀態，不改變 provider 協定。每個 `OperationRecord` 保存前一個有效位元組樣本、樣本時間及指數平滑後的 bytes/second：

- 只用單調遞增的 `completed_bytes` 計算。
- 第一個樣本、Preparing、沒有位元組增量或時間間隔無效時不顯示速度。
- 活動傳輸以最近增量除以單調時間差，再用偏重近期值的 EMA 平滑，避免 ADB／SFTP chunk 邊界造成數字劇烈跳動。
- 終止後保留最後有效速度於本次記錄，但完成摘要不強制顯示。
- 格式使用 `B/s`、`KB/s`、`MB/s`、`GB/s`。

## 0.2 秒更新契約

遠端 transfer reporter 以 200 ms 作為一般進度發布間隔，階段切換、項目邊界、終止與取消仍立即發布。ADB runner 必須持續消費 adb stdout/stderr 的原生進度；若 adb 在活動傳輸期間沒有在 200 ms 內提供新百分比，runner 仍發布保活快照，讓 UI 的時間與取消狀態保持活躍，但不得虛構位元組增加。

UI 合併同一 request 的事件並拒絕倒退或終止後遲到的事件。更新頻率是「最多每 0.2 秒一筆可見狀態」，不要求在沒有任何 provider 新資訊時偽造百分比。

## 右上 Fluent 傳輸面板

主工具列右側新增傳輸圖示。活動工作時使用 accent 徽章顯示數量，沒有活動工作時維持一般按鈕外觀。面板：

- 使用 Fluent 圓角、陰影、surface、hover 與焦點樣式。
- 每列顯示目前項目或操作摘要、狀態、百分比、已傳／總量、速度及進度軌。
- 活動列提供取消；取消中停用按鈕並顯示狀態。
- 終止列顯示完成、取消、部分完成或詳細失敗原因，並提供導向位置動作。
- 點擊按鈕切換面板；點擊外部或按 Escape 關閉。

## Shift+Delete

永久刪除在確認與執行期間不渲染底部 OperationCenter，也不提供該區 Cancel。完成、取消、部分完成或失敗事件抵達後，才顯示包含完整路徑與結果的底部訊息，之後按八秒契約淡出。記錄仍可在右上面板查閱到程式關閉。

## 錯誤與取消

- 每個工作仍以 request ID 精準取消，不影響其他傳輸。
- 取消立即更新 UI，provider 終止後形成唯一終止結果。
- 多工作其中一筆失敗或先完成，不得清除其他工作或阻止底部回退。
- ADB／SFTP 原始錯誤保留操作、來源、目的地、階段、原生錯誤碼與使用者可讀原因。

## 驗證

- 模型測試：穩定排序、前景回退、活動數、速度計算、終止後拒絕遲到進度。
- UI 測試：速度文字、底部單工作、右上徽章／面板、Escape／外部關閉、Shift+Delete 隱藏與終止顯示。
- Provider 測試：ADB 原生解析與 200 ms 保活、SFTP／通用 reporter 200 ms 節流、取消立即終止。
- 使用者視角：同時啟動至少兩筆工作，讓較新的先結束並確認回退；實測 ADB 與 SFTP 大檔案速度和取消；實測 Shift+Delete 執行中不顯示、完成後才顯示。
