# 圖示檢視 Shell 圖示與縮圖載入修正設計

日期：2026-08-05  
狀態：已核准

## 背景

SuperExplorer 在「特大圖示、大圖示、中圖示、小圖示、並排」模式中，部分可見項目只顯示 fallback 色塊，沒有顯示目前尺寸對應的 Windows Shell 圖示或內容縮圖。詳細資料模式可能仍正常，因此問題集中在檢視模式切換後的尺寸需求、pending 工作、快取鍵與呈現鍵協調，而不是單一檔案格式解碼器。

## 目標行為

行為與 Windows 檔案總管一致：

- 特大、大、中圖示優先顯示圖片與影片內容縮圖。
- 內容縮圖尚未完成或無法產生時，必須立即保留相同顯示尺寸的正確 Shell 圖示，不得只留下藍色 fallback。
- 小圖示與並排模式顯示目前尺寸對應的正確 Shell 圖示。
- 快速切換檢視模式或調整圖示大小時，不得讓舊尺寸、舊 DPI、舊資料夾 generation 的完成結果覆寫目前畫面。
- 已完成且相容的快取可重用；切換模式不得無條件清空所有圖示快取。

## 採用方案

採用「尺寸世代化的可見項目管線」。每次提交可見項目載入時，依下列欄位建立目前需求簽章：

- 分頁識別與資料夾 generation；
- Windows DPI 與色彩主題；
- 檢視模式與實際 Shell 圖示尺寸；
- 縮圖模式與實際縮圖尺寸；
- Shell association generation 與項目 overlay generation。

簽章改變時，只取消或排除不再符合目前呈現需求的 pending 工作。已完成的 Shell 圖示與縮圖仍由完整快取鍵管理，尺寸及其他欄位相容時可以直接重用。

不採用以下方案：

- 切換模式便清空所有快取：會造成可見閃爍、重複 Shell 工作與不必要的磁碟負載。
- 永遠請求最大圖示再縮放：無法保證 Shell 在每個尺寸提供最佳 raster，也會提高記憶體用量並使小圖示模糊。

## 請求與容量模型

Shell 圖示與內容縮圖使用各自獨立的可見項目容量。Shell 圖示的 pending 數量不得扣除縮圖容量，縮圖 pending 數量也不得阻止 Shell fallback 請求。每個目前可見項目依模式執行：

1. 建立目前尺寸的 Shell 呈現鍵並確保 Shell 圖示或共用 base icon 請求已提交。
2. 若模式允許縮圖且未啟用「永遠顯示圖示」，另外建立目前尺寸的縮圖鍵。
3. 縮圖完成後，以目前呈現鍵覆蓋該尺寸的 Shell 圖示；縮圖 fallback 或失敗不移除 Shell 圖示。
4. 完成事件必須先驗證分頁、資料夾 generation、尺寸、DPI、association 與 overlay generation，才可改變目前畫面。

## 模式策略

| 檢視模式 | Shell fallback | 內容縮圖 |
|---|---:|---:|
| 特大圖示 | 目前實際圖示尺寸 | 優先，256 logical px 策略 |
| 大圖示 | 目前實際圖示尺寸 | 優先，96 logical px 策略 |
| 中圖示 | 目前實際圖示尺寸 | 優先，64 logical px 策略 |
| 小圖示 | 目前實際圖示尺寸 | 不提交 |
| 並排 | 40 logical px | 不提交 |

資料夾、一般檔案、圖片與影片都必須先有 Shell fallback。圖片與影片的縮圖是漸進式替換，不是呈現該項目的先決條件。

## 失敗與恢復

- Shell 或縮圖服務暫時過載時，保留目前 fallback 並安排 bounded retry。
- 縮圖解碼失敗時記錄負向結果，但不得把已存在的 Shell 圖示移除。
- 舊 generation 或舊尺寸完成事件只完成其 scheduler bookkeeping，不進入目前呈現快取。
- 檢視模式快速切換後返回先前尺寸時，可以直接重用仍有效的完成快取。

## 測試設計

### Rust 測試

- 五種受影響模式產生正確 Shell 圖示尺寸與縮圖策略。
- 舊尺寸 pending 工作不占用目前尺寸的可見容量。
- Shell 與縮圖容量彼此獨立。
- 縮圖成功覆蓋目前尺寸的 Shell fallback；縮圖失敗保留 fallback。
- 舊分頁、generation、DPI 或尺寸結果不能改變目前呈現。
- 快速切換模式後返回原尺寸可命中完成快取。

### Headful UTIT

以測試擁有的資料夾建立資料夾、一般檔案、JPG 與可取得縮圖的影片，依序切換特大、大、中、小圖示與並排模式。每個模式記錄 screenshot、UIA 項目、檢視尺寸與載入終態，並驗證：

- 沒有可見項目停留在藍色 fallback；
- JPG 與影片在前三種模式使用內容縮圖或有證據支持的 Shell fallback；
- 小圖示與並排顯示正確 Shell 圖示；
- 快速來回切換不顯示舊尺寸 raster；
- 捲動後新進入 viewport 的項目同樣完成載入。

測項必須註冊至 `uitest/manifest.json`，失敗時保留報告、log 與各模式 screenshot。

## 範圍界線

本變更只處理檔案檢視中的 Shell 圖示、內容縮圖、可見請求與模式切換協調。不重寫 Shell STA、縮圖解碼器、導覽列圖示或外掛 ABI，也不改變使用者的「永遠顯示圖示」設定語意。
