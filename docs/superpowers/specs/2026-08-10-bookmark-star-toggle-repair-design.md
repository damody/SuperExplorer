# 書籤星號切換修復設計

## 目標

恢復書籤工具列星號的直接切換行為：單選實體檔案或資料夾時，按下 `☆` 立即加入書籤並顯示 `★`；再次按下 `★` 立即移除書籤並恢復 `☆`。星號固定在工具列最左側，尺寸需比一般文字明顯。

## 根因與方案

星號動作誤用 `NamespaceCommand::Pin` 的可用性判斷。該 Shell 命令與應用程式內建書籤沒有相同的前置條件，因此 Shell 可用性變更會攔截星號動作。

採用獨立判斷：`ToggleSelectedBookmark` 只依賴目前是否恰好選取一個可解析為檔案系統路徑的項目。書籤目標比對、mutation、持久化與失敗 rollback 維持既有流程。

## UI

星號維持書籤列第一個 flex child，不參與書籤排序或 overflow。字級提高至 20 px，維持既有 32 px 工具列高度、hover 樣式與無障礙名稱。

## 驗證

- 單元測試確認星號位於書籤集合之前，且不再使用 absolute 舊版面。
- 動作可用性測試確認星號不依賴 Shell Pin 命令。
- Headful UITEST 分別對資料夾與檔案執行加入、取消、再加入。
- 保存 `☆` 與 `★` 截圖，並驗證星號位於第一個書籤左側。
