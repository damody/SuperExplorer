# 書籤資料夾與 Lua 編輯器修復設計

## 目標

修復工具列 `+` 開啟 Lua 書籤編輯器後，名稱與原始碼輸入欄位不可見、無法操作而造成畫面看似卡住的問題；並將書籤改為可包含資料夾的樹狀結構，使「我的最愛」區塊可以如 Firefox 以右鍵建立、重新命名及刪除書籤資料夾。按下星號時，顯示可選擇目的資料夾、編輯名稱及移除既有書籤的編輯器，不再直接無提示切換。

## 決策與範圍

「我的最愛」在本變更中指 SuperExplorer 的持久化書籤集合與左側 Quick access 投影；不建立或刪除 Windows 檔案系統資料夾。書籤資料夾只是使用者收藏的組織節點，可包含資料夾、檔案、Lua 指令及子資料夾。既有扁平書籤會無損遷移為根節點項目。

Lua 編輯器使用顯式邊框、填色、文字與游標色的輸入欄位，首次開啟時聚焦名稱欄；Escape、取消及點擊遮罩均可安全關閉。儲存失敗時保留草稿與對話框；成功後才關閉。

星號在實體資料夾位置啟用。若尚未收藏，開啟「新增書籤」對話框，預填目前資料夾與名稱，使用者可從根目錄或任一書籤資料夾選擇位置。若已收藏，開啟「編輯書籤」對話框，並提供「移除書籤」破壞性按鈕。非檔案系統位置保持停用。檔案與資料夾項目的原有「加入書籤」選單同樣開啟目的地選擇器。

## 架構與資料流

模型以穩定 UUID 的樹狀節點取代根層扁平排序：每個節點為 Folder 或 Bookmark，皆具有 `parent_id` 與同層順序。Folder 無目標 payload，Bookmark 才有 Folder/File/Lua payload。模型提供子層列舉、目標去重、移動、刪除（資料夾遞迴刪除前要求確認）與舊版 JSON 升級。UI state 是唯一 mutation 入口，背景 session 持久化與失敗 rollback 延續既有模式。

左側「我的最愛」投影根層資料夾及展開中的子節點，右鍵選單以被點擊的節點為準：空白處／根區可新增資料夾；資料夾可新增子資料夾、重新命名或刪除；書籤可編輯、移除或移動。工具列顯示根層可啟用書籤與資料夾下拉選單；溢位保持同層順序。書籤對話框使用可存取的 Folder picker tree，而不是自由文字路徑。

## 錯誤處理、安全性與相容性

Lua 仍只在使用者點選時，以背景工作執行並只提供唯讀 `current_folder`；本變更不增加 Lua 權限。無法持久化時還原資料，顯示通知並保留編輯草稿。刪除非空書籤資料夾先顯示節點數與確認對話框。遷移對缺失父節點、循環及非法排序採安全恢復：提升為根節點或拒絕損壞項目，絕不刪除有效書籤。

## 驗收與計畫

1. 建立模型樹、session 遷移及單元測試，證明既有 session、遞迴刪除、移動與 rollback 正確。
2. 修正 Lua 編輯器的可見輸入樣式、焦點和取消／儲存生命週期，建立聚焦 UI 測試與實機截圖。
3. 實作書籤資料夾 CRUD、左側右鍵選單、根層／子層投影與確認刪除。
4. 以 Firefox 式目的地選擇器取代星號與加入書籤的立即切換，支援更新與移除。
5. 更新工具列、溢位及管理員以支援樹狀資料夾與不遺失排序。
6. 執行模型、UI、session、Lua 回歸與 headful UI 測試，保存截圖和遷移證據。

## 非目標

不建立瀏覽器 URL 書籤、同步、匯入匯出或 Windows 資料夾操作；不變更 `.explorer.lua` 移除策略；不擴張 Lua host API。
