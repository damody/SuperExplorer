# ADB／SFTP Windows 11 右鍵選單設計

## 目標

讓 ADB 與 SFTP 資料夾中的項目右鍵選單及空白處右鍵選單，在視覺與互動上對齊 Windows 11 檔案總管，同時保留既有遠端檔案操作、剪貼簿、選取、定位與關閉行為。

## 決策

採用 GPUI 實作 Windows 11 風格的遠端選單，不直接呼叫 Windows Shell 選單。ADB 與 SFTP 路徑不是 Shell 原生項目，若交給 Shell 建立選單，命令目標與執行語意會不正確。

不採用只調整圓角與間距的純外觀修補，因為這仍缺少 Windows 11 的頂部圖示命令列、群組分隔與一致的互動狀態。

## 架構與元件

在 `explorer-ui` 中建立可重用的 Windows 11 選單呈現單元：

- 選單容器：統一寬度、內距、圓角、邊框、背景與陰影，使用現有主題語意色彩支援亮色、深色與高對比模式。
- 圖示命令列：項目選單頂部顯示剪下、複製、重新命名、刪除；每個命令具有圖示、無障礙標籤、hover、pressed、disabled 與鍵盤焦點狀態。
- 文字命令列：顯示開啟、貼上、新增資料夾等適用命令；使用一致列高、左右圖示槽、文字與可選快捷鍵槽。
- 分隔線：將主要動作、剪貼簿動作與破壞性動作分組。
- 遠端命令描述：將標籤、圖示、動作、是否危險、是否啟用及呈現區域集中描述，避免 ADB 與 SFTP 各自產生不同外觀。

## 選單內容

項目右鍵選單：

- 頂部圖示列：剪下、複製、重新命名、永久刪除。
- 文字區：開啟；若剪貼簿內容可貼入目前資料夾，顯示貼上。
- 永久刪除仍使用遠端既有確認與操作流程，不改成資源回收筒語意。

空白處右鍵選單：

- 新增資料夾。
- 剪貼簿內容可用且目前位置可寫入時顯示貼上。
- 使用相同容器、列高、圖示槽與互動狀態。

只顯示目前命名空間支援的命令，不新增無法對 ADB／SFTP 正確執行的 Windows Shell 擴充命令。

## 資料與事件流程

右鍵命中測試與遠端能力判斷沿用現有 `RemoteContextMenuState`。呈現層依項目／背景及貼上可用性建立命令描述，再轉成圖示列與文字列。點擊後仍派送既有 `ExplorerAction`，由目前的 ADB／SFTP 操作管線執行。

外層遮罩維持點擊選單外關閉；選單內的滑鼠按下事件停止傳播，避免游標移入或點擊時提前消失。位置計算以實際選單尺寸限制在視窗範圍內。

## 錯誤處理

選單本身不吞掉遠端操作錯誤。命令執行失敗仍交由既有詳細操作訊息列顯示來源、目的地、操作與底層原因。不可用命令在呈現前隱藏或停用，避免送出已知無效動作。

## 驗證

所有檢查集中在實作完成後執行：

- 單元測試：命令分組、貼上可用性、危險命令、位置邊界與選單內事件不關閉。
- UI 驗證：分別在 ADB 與 SFTP 的資料夾項目及空白處開啟選單，檢查亮色／深色外觀、圖示、分隔線、hover、點擊、視窗邊界與選單關閉。
- 行為驗證：開啟、剪下、複製、貼上、重新命名、新增資料夾與永久刪除仍走既有遠端流程，並確認本機右鍵選單不受影響。

## 非目標

- 不把 ADB／SFTP 註冊成 Windows Shell namespace extension。
- 不載入第三方 Shell 擴充選單。
- 不改寫遠端傳輸或檔案操作後端。
- 不進行與此選單無關的完整迴歸測試。
