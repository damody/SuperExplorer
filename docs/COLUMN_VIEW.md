# 分欄檢視

分欄檢視是本機磁碟資料夾的 Finder 式瀏覽方式。View 選單的「分欄 / Columns」只對本機固定或卸除式磁碟的磁碟機代號路徑生效。

## 操作

- 單擊資料夾會選取該列、在下一欄顯示其子項目，並以正式導覽更新網址、麵包屑與上一頁／下一頁。再次單擊目前資料夾不會新增歷史紀錄。
- 單擊檔案會保留所在資料夾為目前位置，並在右側整合預覽顯示該檔。影像沿用現有縮圖；其他檔案沿用 Windows Preview Handler。無法預覽、處理常式失敗或離線預留位置時顯示既有的可復原狀態，且不會為了預覽而強制下載雲端預留位置。
- Alt+P 與「預覽窗格」命令在分欄生效時只切換這個整合預覽，不會再開第二個預覽窗格，也不會改寫其他檢視模式的預覽窗格設定。
- 路徑比視窗寬時可水平捲動。每一欄可獨立垂直捲動，分隔線可調整欄寬。縮小視窗或變更 DPI 不會丟掉選取或祖先欄。
- 方向鍵在欄內移動，Right 展開資料夾欄，Left 回到父欄選取。Shift+上下鍵延伸同一欄的選取範圍，Ctrl+空白鍵切換目前項目的選取。Enter 對檔案沿用既有開啟方式。
- 右鍵、重新命名、複製貼上、拖放、刪除與 F5 作用在作用中欄的實際項目與其父資料夾。
- 空資料夾會顯示「此資料夾是空的」及「重試」；列舉失敗會顯示錯誤與重試，父欄仍可用。

## Windows 手動檢查

1. 在本機磁碟建立 `A\B`，並分別在 `A` 和 `B` 放入不同名稱的測試檔。從 `A` 啟動程式，在「檢視」選單選「分欄」。
2. 單擊 `B`。檢查右側新增一欄、位址列指向 `B`；按上一頁與下一頁，確認欄位、位址列及選取同步變化。
3. 選取 `B` 的 JPEG 檔，檢查右側影像確實出現。按 Alt+P 關閉，再按一次開啟。選取其他檔案時，舊影像應立即消失。
4. 把視窗縮窄，使用底部水平捲軸返回祖先欄；滾動任一欄的滑鼠滾輪時，其他欄的垂直位置應保留。拖動欄間及預覽分隔線，檢查寬度變化。
5. 在祖先欄選取測試檔，按 F2 重新命名；再試右鍵、複製貼上、Delete 與拖放，確認命令針對畫面選取的檔案及目的資料夾。這些操作會修改檔案，請只用測試資料。
6. 開啟空資料夾，檢查空狀態與重試控制。切到 UNC 或 WSL 位置，確認畫面改用詳細資料檢視；返回本機路徑後，分欄偏好應恢復。

## 不支援的位置

UNC、對應的網路磁碟、WSL、Shell 命名空間、壓縮檔、虛擬資料夾，以及 ADB／SFTP／FTP／Google Drive 會顯示詳細資料檢視。分欄偏好會保留；回到合格的本機資料夾時會恢復分欄。
