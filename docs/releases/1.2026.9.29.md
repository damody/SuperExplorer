# SuperExplorer 1.2026.9.29

Windows 11 x64 安裝包。

## 本版更新

- 分欄模式可將 ZIP、7z、RAR 等壓縮檔當作唯讀資料夾瀏覽，支援內部資料夾切換、上一頁及檔案預覽。
- TXT、MD 顯示純文字，最多預覽前 3000 個 Unicode 字元；支援 UTF-8、具 BOM 的 UTF-16 及 Windows 本機編碼。
- 圖片預覽加入 EXIF、長寬、檔案大小及原始色彩深度資訊。
- 長檔名最多兩行，超出部分截斷，修正行距與項目重疊。
- 每個檔案欄位可拖曳右側分隔線調整寬度，修正拖曳重繪及滑鼠釋放時的狀態。
- 修正書籤列虛擬資料夾的圖示。

## 安裝與附件

- `SuperExplorer-Setup-1.2026.9.29-x64.exe`：SuperExplorer NSIS 安裝程式，包含 MFT 服務、預覽隔離元件、Everything SDK DLL 與八個既有內建外掛。
- `SuperExplorer-1.2026.9.29-release-manifest.json`：來源提交與封裝內容的 SHA-256、大小。
- `SuperExplorer-1.2026.9.29-SHA256SUMS.txt`：下載檔案校驗碼。

壓縮檔讀取優先使用已安裝的 7-Zip，並可使用 Windows 內建 tar。密碼輸入及巢狀壓縮檔的遞迴瀏覽尚未提供；壓縮檔內容目前為唯讀。

## 驗證

本次通過 workspace 編譯檢查、193 個模型測試、82 個分欄相關 UI 測試、28 個預覽相關 UI 測試，以及實際 ZIP、7z、RAR、RAR5 的讀取測試。測試篩選有交集，數量不能相加。本次包含 GPUI 渲染及服務整合測試；安裝後的原生視窗互動仍需手動驗收。
