## 1. 當事人、接受與準據文本

本貢獻者授權協議（下稱「CLA」）由 Damody 與提交貢獻的個人或實體（下稱「您」）訂立。您可透過作出[貢獻指南](CONTRIBUTING.zh-TW.md)要求的接受聲明、使用核准的 CLA 系統簽署，或簽署獨立副本來接受。Damody 於合併貢獻或以書面確認時接受本 CLA。

三語版本應具有相同含義。如翻譯或解釋不一致，以[簡體中文版本](CLA.zh-CN.md)為準。

## 2. 貢獻

「貢獻」是指您有意提交以納入 SuperExplorer 核心、Repository 自有 SDK 素材或專案自有資產的任何原創程式碼、文件、設計、測試、資料、美術、Patch 或通訊。一般回饋及獨立發行的插件，不屬於貢獻，但明確提交納入者除外。

## 3. 保留所有權

您保有原創貢獻的著作權。本 CLA 是授權而非著作權讓與。第三方素材的所有權仍歸其權利人。

## 4. 著作權授權

您授予 Damody 及其繼受人永久、全球、不可撤銷、免權利金、已付清、可轉讓且可再授權的權利，得依貢獻的所有著作權及類似權利：

1. 以原始碼或二進位形式使用、重製、修改、改作、翻譯、組合、創作衍生作品、公開展示、公開演出、提供、發布及散布；
2. 製造、委託製造、輸入、輸出、託管、營運、行銷、授權、出租、銷售、要約銷售及以其他方式商業利用包含貢獻的產品或服務；
3. 執行已授權的權利；以及
4. 重新授權貢獻（包括採專有條款），並無須另行同意或付款即可變更 SuperExplorer 授權條款。

本授權自提交時生效，且在貢獻遭拒絕、撤回、移除或終止後，於 Damody 已收受或信賴貢獻或權利的範圍內繼續有效。

## 5. 專利授權

您授予 Damody、接收者、發行者及客戶永久、全球、不可撤銷（但下述情形除外）、免權利金、可轉讓且可再授權的專利權利，以製造、委託製造、使用、要約、銷售、輸入及以其他方式利用貢獻及其與 SuperExplorer 的組合；但僅限您控制且因貢獻本身或提交時的組合而必然受侵害的專利請求項。

若您提起專利訴訟，主張 SuperExplorer 或某項貢獻侵害專利，您就被指控作品所取得的專利授權，在法律允許範圍內自起訴日終止。

## 6. 人格權及類似權利

在法律允許的最大範圍內，您放棄且同意不主張會妨礙行使本 CLA 的著作人格權、精神權利、完整性、撤回、署名及類似權利。法律不允許放棄時，您同意本 CLA 授權的行為，並在法律允許範圍內不執行該等權利。Damody 得提供署名，但除強制法律或已揭露的第三方授權要求外，無此義務。

## 7. 您的聲明

您聲明：

1. 您具備訂立本 CLA 的法律能力及授權；
2. 貢獻是您的原創作品，或您已揭露並遵守所有第三方條款；
3. 您擁有授予本 CLA 所必要的權利；
4. 就您所知，貢獻不侵害、挪用或非法揭露他人的權利、機密資訊、個人資料或營業秘密；
5. 貢獻不含惡意程式或故意隱藏行為；且
6. 已揭露所有重大 AI 輔助或生成內容及其相關使用限制。

上述是對權限及知情範圍的聲明，不保證貢獻毫無缺陷。

## 8. 雇主及實體授權

若您的雇主或其他實體可能擁有或控制貢獻，您聲明已取得提交及授予本 CLA 的授權。若您代表實體接受，您聲明有權拘束該實體，且「您」包括該實體。Damody 得要求權利人書面確認。

## 9. 第三方素材

請在 Pull Request 中標明第三方程式碼、資產、工具、生成素材及授權。除非 Damody 書面核准，不得提交與 SuperExplorer 專有發行或 Damody 行使本 CLA 不相容的素材。本 CLA 不變更任何第三方授權。

## 10. 無保密、報酬或支援義務

請勿提交機密資訊。除另有書面協議外，貢獻不以保密方式接收。提交不產生僱傭、合夥、代理、付款、權利金、支援、維護或接受義務。付費工作得另以書面協議規範。

## 11. 紀錄與通知

GitHub 帳戶、Pull Request、Commit ID、接受聲明及時間戳得保存作為本 CLA 的證據。您應合理維持重大法律通知所需的聯絡資訊。通知得透過 Repository、關聯帳戶或您提供的其他地址送達。

## 12. 免責與限制

除上述明示聲明外，您依「現狀」提供貢獻且不附保證。在法律允許的最大範圍內，任一方均不對本 CLA 下的間接、附帶、特殊、懲罰性或衍生損害負責。本限制不免除詐欺、故意不法行為、違反保密、因明知未授權素材造成的侵權，或依法不得限制的責任。

## 13. 準據法、爭議及一般條款

本 CLA 適用中華人民共和國法律。經 30 日友好協商後，爭議應由 CIETAC 依申請時有效規則在北京以中文進行一名仲裁員的終局仲裁。英文證據可提交，但被要求翻譯者除外。不得放棄的消費者保護及小額程序救濟仍可使用。任一方得在任何有管轄權地區，對侵權、未授權散布或違反保密義務尋求緊急法院救濟。

條款無法執行時，應在必要最小範圍內限縮或分離，其餘繼續有效。除簽署的協議明確取代外，本 CLA 構成貢獻事項的完整協議。問題可透過 [SuperExplorer GitHub Repository](https://github.com/damody/SuperExplorer)提出。
