**產出：** 檔案系統身分／值型別、序列化資訊清單欄位、協定描述子欄位、轉換邏輯與測試資料。
**依賴：** 無。

**完成門檻：** 所有契約層均表達相同的封閉值集合與預設拒絕行為，且不存在使用者可覆寫的途徑。

- [x] 1.1.1 在權威模型／擴充描述子契約中加入封閉的 `local`／`adb`／`sftp` 檔案系統身分與不可變適用性集合，並定義穩定的序列化名稱。
- [x] 1.1.2 擴充資料欄位資訊清單／結構描述解析，使缺少或空白範圍正規化為空集合、重複的已知值去重，未知值則以一次有界診斷拒絕受影響的 contribution。

## 2. 遠端中繼資料實作

### 2.1 共用 Unix mode 與格式化

**目的：** 傳遞可選的 Unix mode，並提供唯一且正確的符號加八進位格式化器與數值排序值。
**輸入：** Permissions 登錄契約；現有 `FileEntryMetadata`、資料列儲存格、篩選與排序值模式。
**產出：** 可選 mode 中繼資料、格式化器、缺少值的呈現方式，以及篩選／排序整合。
**依賴：** 1.2。
**Owner／Wave：** 主要代理程式／第 2 波。
**Gate／Evidence：** UNIX-MODE-MODEL；`evidence/index.jsonl` 中任務 2.1.1–2.1.3 的紀錄。
**完成門檻：** 標準檔案類型、特殊位元、未知類型、八進位數字、缺少值與數值順序皆使用同一套實作。

- [x] 2.1.1 在共用項目中繼資料，以及所有必須保留該值的建構、協定轉換、snapshot、相等性與測試資料路徑中加入可選 Unix mode。
- [x] 2.1.2 實作符號式檔案類型／權限格式、`s`／`S`／`t`／`T` 處理、四位數八進位格式、未知類型 `?` 與缺少值的破折號呈現。
- [x] 2.1.3 整合 Permissions 儲存格／篩選／排序值，使排序採用數值 mode、升冪時已知值位於缺少值之前，降冪行為亦具確定性。

### 2.2 SFTP 與 ADB mode 取得

**目的：** 從兩種遠端 provider 填入 Unix mode，且不改變清單失敗語意，也不引入逐項處理程序或紀錄放大。
**輸入：** 工作包 2.1；現有 SFTP attributes 與 ADB 有界目錄清單／解析器實作。
**產出：** SFTP mode 映射，以及 ADB 有界目錄層級 mode 收集／解析器映射。
**依賴：** 2.1。
**Owner／Wave：** 主要代理程式／第 2 波。
**Gate／Evidence：** REMOTE-MODE-PROVIDERS；`evidence/index.jsonl` 中任務 2.2.1–2.2.3 的紀錄。
**完成門檻：** 兩種 provider 均可填入有效 mode；缺少或格式錯誤的值降級為 `None`；ADB 不啟動逐列子處理程序。

- [x] 2.2.1 將 SFTP 權限／類型 attributes 映射為可選 Unix mode，同時保留既有符號連結與一般中繼資料行為。
- [x] 2.2.2 擴充有界的 ADB 目錄中繼資料命令與解析器，使每個項目均可回傳 Unix mode，且不得為每個項目啟動一個子處理程序。
- [x] 2.2.3 將 provider 缺少或格式錯誤的 mode 資料處理為非致命狀況，抑制逐項錯誤紀錄，同時保留既有目錄層級錯誤。
